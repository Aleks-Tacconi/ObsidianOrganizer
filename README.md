## Dependencies

- `npm`
- `python 3.12+`
- `poetry`
- `make`
- `mprocs`

## Setup and Usage Instructions

1. Clone the repository 

  ```sh
  git clone git@github.com:Aleks-Tacconi/ObsidianOrganizer.git
  ```

2. Navigate to the repository

  ```sh
  cd ./ObsidianOrganizer
  ```

3. Install dependencies

  ```sh
  make install
  ```

4. Run the program

  ```sh
  make run
  ```
